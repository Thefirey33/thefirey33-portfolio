# Thefirey33's Portfolio

My portfolio website where I make things!

## Information

Inside of `app`, there exists `assets` folder. This is where the static assets are stored, that do not change. Compared to the `public` folder, where all the dynamic assets are stored.

## Getting Started

You must have have a package manager for JavaScript/TypeScript installed on your system. After verifying that you have a package manager installed, you must run the installation command for your package manager.

```bash
npm install
```

to install all the dependencies for NPM. This project used the NPM package manager mostly, and it is recommended. After the installation is done, you can run

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

To create a development server.
